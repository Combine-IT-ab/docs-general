# Web Connect integrations

Web Connect connects Business Central with the systems below. Each page describes what is synchronized, the options for each flow, and what you can configure yourself in Business Central.

All mappings, conditions and triggers are set up in Web Connect in your own Business Central, where you can see and change them.

## E-commerce

| Integration | What is synchronized |
|---|---|
| [Centra](centra/overview.md) | Orders, stock, products, shipments |
| [Shopify](shopify/README.md) | Orders, products, prices, stock, shipments |
| [Norce Commerce](norce/overview.md) | Orders, order status, shipments, stock, products, prices, customers |
| [Crystallize](crystallize/overview.md) | Orders, order status, stock, prices |
| [WooCommerce](woocommerce/overview.md) | Orders, customers, order completion, stock, prices, product matching |

# Job Queue Monitor

## Overview

Job Queue Monitor is a Combine IT extension for Microsoft Business Central that continuously monitors and manages background jobs running in Job Queue Entries.

## What Job Queue Monitor Does

Job Queue Monitor:

- Monitors selected Job Queue Entries
- Detects jobs that fail with errors, run longer than expected, or stop responding
- Automatically restarts jobs and retries execution based on configuration
- Sends email notifications when issues occur
- Logs all monitor actions for traceability

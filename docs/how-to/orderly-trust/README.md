# How-to: Orderly Trust

Orderly Trust sets an order status on each sales order in Business Central, based on rules and conditions that you configure yourself. The status can be shown in Business Central and sent on to external systems such as an e-commerce platform. These guides cover how to set up and troubleshoot order statuses.
